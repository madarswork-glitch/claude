# claude-starter

Minimal starter project for calling the Claude API from Node.js using the official [Anthropic SDK](https://github.com/anthropics/anthropic-sdk-typescript).

## Setup

```bash
npm install
cp .env.example .env   # then add your ANTHROPIC_API_KEY
```

## Run

```bash
npm start
```

This sends a single message to `claude-opus-4-8` and prints the response.
